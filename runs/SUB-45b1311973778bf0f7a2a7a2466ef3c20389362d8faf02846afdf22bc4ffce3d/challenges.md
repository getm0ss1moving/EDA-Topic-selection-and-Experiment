## OBJ-001 — Missing variational-execution comparator for the surviving distinction

**Target:** CLM-1002/1006; proposal Mechanism and Nearest mechanisms; plan B0–B4 and EXP-002/004. **Severity:** major, fixable literature/baseline gap; no fatal impossibility claim. **Confidence:** high for mechanism overlap, unresolved for EDA performance equivalence.

**Evidence:** C01, ASE2016 §3.1 physical pp3–4, especially conditional-value compression, valid input combinations and per-field sharing; C07, OOPSLA2018 §2.1 pp4–5 and §3.2 pp9–10. These already represent alternative concrete values with configuration subsets, lift operations across compatible inputs, and merge equal results. C07 also distinguishes pure external calls from stateful environment integration. This is closer to operation-specific world classes than generic memoization alone.

**Reasoning bridge (own reduction):** Let W be the finite candidate list. Encode each candidate as one valid configuration (an integer ID or constrained Boolean code); no exponentially larger space is necessary. Represent a state as value-to-subset pairs. A primitive combines parent subsets by intersection, drops empty intersections, evaluates each distinct argument tuple and unions subsets yielding identical results. This is the proposed partition/intersection/re-coalescence semantics on its pure acyclic domain. Adding full electrical/code context as another argument preserves the mapping. The mapping does NOT show identical memory allocation, dispatch costs, side effects, or complete STA adapter engineering.

Consequently, novelty of this representation cannot rest on its contrast with ordinary cache lookup alone. B4's unspecified Adapton-inspired comparator does not necessarily instantiate this closer lifting strategy. A useful EDA specialization remains possible, but must identify a concrete administration/data-layout advantage beyond an equally specialized lifted-value baseline.

**Reversal condition:** show a precisely specified operation/state capability or administration technique absent from the cited conditional-value mapping, or demonstrate a useful end-to-end delta against its fair implementation with matched keys, output, specialization effort and memory.

**Cheapest decisive test:** source-level mapping and own bounded masked-value evaluator, followed only under future consent/allocation by a same-language conditional-value baseline. The current own check C12 passes 1,024 bounded arithmetic cases; this supports the reduction, not EDA usefulness. Do not demand porting a JVM into OpenROAD merely to handicap the baseline.

import random,json
r=random.Random(10010)
def groups(xs):
    d={}
    for i,x in enumerate(xs):d[x]=d.get(x,0)|(1<<i)
    return d
def lift(a,b,fn):
    out={};calls=0
    for x,m in a.items():
        for y,n in b.items():
            if m&n:
                z=fn(x,y);out[z]=out.get(z,0)|(m&n);calls+=1
    return out,calls
checks=0
for n in (1,2,4,8):
    for trial in range(256):
        a=[r.randrange(4) for _ in range(n)];b=[r.randrange(4) for _ in range(n)]
        scalar=[max(x,y) for x,y in zip(a,b)]

        assert q==groups([min(x,3) for x in scalar])
        assert d==len(set(scalar))
        checks+=1
