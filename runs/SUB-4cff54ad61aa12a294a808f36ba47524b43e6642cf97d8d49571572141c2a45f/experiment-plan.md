# Conditional experiment plan

No experiment in this plan is authorized by this research release. Scientific position: unresolved hypothesis; resource and consensus gates closed.

## Hypotheses and correctness

H1: retaining shared legal-footprint competition and feeding its scoped cores to sink regrouping improves the all-cost post-route cost-quality frontier beyond ordinary grouping followed by placement and beyond equally informed integrated/LBBD controls. H2, conditional on H1: a conflict-aware learned exchange ranker amortizes exact/electrical evaluation cost across held-out designs. H0: ordinary joint optimization or equal-budget random/conventional search explains the entire gain. H3: centralized control matches specialist workers; coordination labels add nothing.

Finite-domain geometry acceptance requires exact sink coverage and disjoint complete physical footprints on compatible rows/sites/orientations, respecting fixed cells, blockages, padding, rails and master constraints. Completeness of domain enumeration is not assumed. If the true legalizer can move standard cells, either disable such movement in ALL bounded arms or explicitly model it before comparing; otherwise this restriction invalidates a fair main comparison and must be disclosed as a restricted diagnostic. Full-flow CTS baseline remains additionally unrestricted as an engineering reference. Geometry-infeasible labels never mean globally infeasible CTS. No returned clean circuit is certified by the finite solver alone.

## Baselines and matched information

A: pinned stock OpenROAD CTS with obstruction awareness, same knobs, full legalizer/routing/repair flow. B: A clustering plus joint footprint assignment, no core-driven regrouping. C: conventional integrated exact-cover/MIP/CP (exhaustive oracle on tiny cases; bounded optimization on larger ones), plus logic-based Benders/no-good feedback with ordinary best-first/beam search. C gets all features, cores, domain expansions, predictions and warm starts available to H. D: specialist predictors plus fusion and the same conventional controller/checker. U: shared encoder/multi-head predictor under the same labels/parameter and tuning limits. H: conflict-aware repr/ranker plus the same controller/checker. M optional workers versus centralized H and a budget-matched single-agent/repeated-call arm only if actually allocated. Open-source iCTS and available current CTS surrogates are reproduction leads, not assumed ready baselines; S04/S08/S09 details and licenses must be locked first. Keep baseline implementation parity; merge mathematically identical C/H configurations.

Same seed/checkpoint/domain, cell/master choices, clock root, upstream topology policy, option generator, maximum exchanges, exact-solver work caps and fallback across B-H. Stock A is both a fixed-neighborhood adapted reference and a full native engineering reference; never cripple A silently. Every final result pays the same complete legalization, clock and data route, extraction, fixed-corner setup/hold and DRC/connectivity work. If learned models see previous oracle feedback, conventional arms receive the same observations.

## Data, labels and splits

Use rights-cleared placed OpenDB/LEF/Liberty/SDC checkpoints with actual row/site/blockage/occupancy geometry and multiple clock clusters, not only old point-sink contest inputs or summary CSVs. Freeze a census sampling rule before exposing candidate outcomes. Include macro-adjacent, fragmented whitespace, roomy/no-conflict, blocked/no-feasible-enumeration, multi-site-overlap, mixed-orientation and fallback controls. Group every variant/seed/neighborhood of a design together in train/validation/test; hold out whole design families and disclose PDK/tool/corner coverage. At least three independent designs and five paired stochastic seeds per design are the brief's provisional minimum, subject to calibration; report all designs, failures and confidence intervals. Do not call multiple windows of one netlist independent designs.

S08 CTS-Bench is an external predictor/data lead only: macro-dominated extension and legality payload adequacy are not established, its random variant split is not adopted, and summary QoR labels cannot reconstruct footprint assignment. S09 headline speed/accuracy claims are not reproduced. Labels must record a fully enumerated candidate domain, chosen exchanges, exact assignment status and full electrical/flow endpoints. Final-route labels stay offline. Model/LLM pretraining contamination on public designs is unknown. No full paper copies, restricted PDKs or design payloads go into releases.

## Attribution and falsification

EXP-1201 is the public finite model in search-log, already run as a tiny own analytical check. EXP-1202 first establishes whether joint-footprint contention predicts material downstream harm after stock occupancy-aware CTS/legalization. If absent, stop, do not manufacture denser designs and claim representative utility. EXP-1203 validates legality/cut scope; test stale occupancy, omitted candidate expansion, orientation and overlapping buffer footprints. One false positive certificate disables exactness and stops affected trials. Exhaustive small-case C is the oracle, not an ablation deliberately too weak to solve the example.

EXP-1204 decomposes A->B (joint assignment), B->C (ordinary core feedback), C->H (representation/learned amortization). Hold labels, features and compute equal. Ablate shared conflict hyperedges while preserving feature counts, core feedback while preserving exact checks, and learning while preserving candidate evaluations. If C and H coincide, merge them. Compare D/U/H closed-loop decisions; offline error alone cannot pass. Test negative transfer on no-contention and held-out design families. Optional cooperation tests synchrony, duplicate calls, stale state, conflict resolution and centralized equivalence.

## Metrics, threshold lock and cost

Use final post-route WNS ns as primary; guard no new hold violations or route DRC/connectivity failure, plus total area/clock-power/runtime budgets locked before outcomes. Clock skew, insertion latency, leaf displacement, solver counts and prediction errors explain mechanisms only. Baseline variance, census and a practitioner discussion must set meaningful effect and timeout rules before candidate arm scores; missing practitioner access is an unresolved dependency. Do not promise +0.02 ns or a speedup. Freeze confirmatory design count using separate calibration data and write a signed preregistration; later changes require new role consent.

Charge enumeration/row occupancy construction, source queries, canonicalization and invalidation, LP/CP/exact solves and proof/core extraction, domain expansion, sink exchanges, rejected proposals, snapshot/restart, electrical estimates, full-flow fallback, model labels/training/tuning/inference, communication, tokens, failed actions, CPU elapsed/core time, peak memory and storage. No remote/GPU/paid or EDA budget exists in this job; requested amounts remain null pending a named allocation.

## Reproduction and stopping

Preimplementation constants: <=32 sinks, <=8 leaves, <=64 placement options per leaf subset, <=16 exchange candidates/iteration, <=8 iterations. Total distinct subsets/options may exceed these local caps; EXP-1203 must pin the subset generator and global memory/work bound before implementation, with overflow fallback. Do not infer total cost by multiplying only scoring dimensions. A solver timeout gives UNKNOWN and ordinary fallback, not infeasible. Instrument each stage and reserve full-flow verification time; insufficient reserve means no verified completion.
