# Industry gap and adoption boundary

The engineer owns the post-detailed-placement optimization window before CTS. The choice is whether and in which order to realize a width-changing size edit and a congestion-driven relocation. The endpoint is a legal, functionally equivalent routed design with acceptable setup timing, area/power and complete iteration cost. S06 §2.2 and S11 §§2.1–2.4 provide primary evidence of coupled timing/placement/space demands. Specific incidence and a financially meaningful improvement threshold are unresolved, assigned to EXP-002/003. No claim is made that every design or commercial flow needs this feature.

OpenROAD at 3549d60529517dc82deb7f0ff769345e9a424911 is a source-inspected candidate backend. MoveCommitter nested journaling and Optimizer policies are already sophisticated (S05), so simple transaction/rollback support is not a gap. Opendp accepts incremental placement parameters and updates database locations. Actual action adapter behavior, supported masters and restore integrity must be validated. ORFS 08ddc64f89c66b7e8398587d25bbaf55858d1fe5 is a candidate flow lock; current HEAD pairing has not been built. A failed compatibility preflight requires a written paired-lock amendment, not mixing engines across arms.

AgenticPD author code is pinned at 3456161b829ee2cc4888cbe57b279d2733452367 (S04): typed stage proposals and checkpoint inheritance exist. This is a strong agent/system baseline, not proof that a stage controller already implements or cannot implement pair contrasts. ChatEDA and EDAid are source-grounded orientation systems (S01/S02). Full scripts, models, permissions and cost must be reproduced fairly before numerical comparison; a one-shot single-agent straw comparator is forbidden.

Synopsys publicly advertises DSO.ai PPA search and integration (S15). The advertised capability defeats any blanket “industry has no autonomous PPA optimization” premise. We have no access to its proprietary implementation, license, controlled trials or paired-order model. Its internal absence, inferiority or adoption difficulty is unknown. Vendor numerical gains do not transfer to this topic. Public algorithms and rights-audited open flows are the proposed initial evaluation environment; commercial comparisons are optional only if separately resourced.

The hypothesis concerns the sample/cost utility of a particular conditional label factorization. It is not an open-source feature request disguised as novelty. Separate algorithmic value from adapter engineering, data creation and incidental environment repair. Charge netlist/geometry snapshots, feature extraction, checkpoint copy, legalizer calls, router/STA calls, predictions, failed orders and final routing. A local spatial support is a model feature, never a correctness boundary; returned placement may change outside it. Fresh whole-design checks are necessary for every accepted incumbent.

Threshold delta_quality and allowed cost/area/power bounds must be written by an engineering owner before confirmatory tests. The current document supplies no owner-approved numeric thresholds. EXP-002 can propose thresholds from noise and workflow cost; absence of an approval/allocation keeps physical advancement conditional, without invalidating the research question. Adoption requires a small declarative edit adapter, a model/version manifest, explicit FAIL/UNKNOWN/KEEP outputs, a replay log and a fail-closed incumbent. The claimed benefit fails if these costs erase the gain or final DR overturns it.
