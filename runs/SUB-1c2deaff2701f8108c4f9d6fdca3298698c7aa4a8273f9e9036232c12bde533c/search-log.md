## Executed analytical sanity check, not an EDA experiment

Exact lightweight Python procedure (stdlib only, zero tool/model/training calls). It ran once locally in less than one shell second; no CPU billing/industrial timing was measured. The toy legalizer is intentionally defined here, not copied from or claimed equivalent to OpenROAD.

```python
from copy import deepcopy
state={'A':(0,1),'B':(3,1)}
def overlap(x,w,y,v): return x < y+v and y < x+w
def apply(s,cell,x,w):
    s=deepcopy(s); s[cell]=(x,w)
    for other in sorted(s):
        if other==cell: continue
        y,v=s[other]
        if overlap(x,w,y,v):
            candidates=[z for z in range(7-v)
                if all(k==other or not overlap(z,v,p,t)
                       for k,(p,t) in s.items())]
            if not candidates: return None
            s[other]=(min(candidates,key=lambda z:(abs(z-y),z)),v)
    assert not overlap(*s['A'],*s['B'])
    return s
def a(s): return apply(s,'A',s['A'][0],2)
def b(s): return apply(s,'B',1,s['B'][1])
def q(s): return -(abs(s['A'][0]-5)+abs(s['B'][0]))
sa,sb=a(state),b(state); sab,sba=b(sa),a(sb)
for name,s in [('s',state),('a',sa),('b',sb),
               ('a_then_b',sab),('b_then_a',sba)]:
    print(name,s,q(s))
print('additive_prediction',q(sa)+q(sb)-q(state),
      'residuals',q(sab)-q(sa)-q(sb)+q(state),
      q(sba)-q(sa)-q(sb)+q(state))
```
