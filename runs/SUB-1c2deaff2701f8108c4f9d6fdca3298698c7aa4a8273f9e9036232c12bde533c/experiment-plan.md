# Conditional experiment plan

## Hypothesis and comparison

EXP-001 checks novelty before physical work. If it survives, test CLM-009: symmetric interaction plus antisymmetric order-contrast prediction changes the next admitted order beneficially under the same candidate set, labels, features and complete budget. CLM-010 (order externality exists frequently enough above noise) is a prerequisite, not an established observation. Neither requires a new theorem or super-additive gain. All subsequent steps are **conditional requests**, not allocated runs.

## Boundary, oracle and primary endpoint

Use one legal pre-CTS ideal-clock, single-PVT checkpoint. Primitive resize and relocation semantics are fixed in proposal.md. Physical action adapter must report requested/returned geometry and master changes globally, including unrelated moved cells, with placement/fixed/displacement checks. Primitive failure is a categorical outcome. Whole-design GR plus declared RC extraction and OpenSTA assesses numerical feedback. Netlist equivalence, electrical limits, utilization, fixed objects and placement/routing blockages are checked. A fixed suffix supplies CTS (if needed by the declared flow), DR, extraction and route timing/power checks for all compared incumbents; freeze identical suffix settings before labels. Pre-CTS ranking targets cannot become post-CTS signoff guarantees.

Primary decision endpoint: total charged time to reach a prespecified post-DR feasible quality target, including censored failures at cap. Complement: best feasible post-DR effective period Tclk-WNS versus complete CPU-seconds and elapsed time. Report TNS, power, area, DRC/overflow/failure tails. Do not percent-normalize by possibly zero WNS. Engineering target and noninferiority limits are **unresolved until EXP-002**, so confirmatory tests are blocked. Proxy error is diagnostic only.

## Strong and composition controls

B0 native pinned OpenROAD repair plus incremental placement; retain its default relevant policy capabilities. B1 deterministic serial greedy with refresh/reproposal after each action, both fixed order heuristics and best tuning selected on validation data. B2 equal-cost beam/lookahead or enumeration of both orders, charged actual calls. B3 nonlinear direct joint predictor (GBDT or small MLP) of each ordered outcome, with swap augmentation and all identical labels/features. B4 separate WNS/overflow models plus tuned nonlinear fusion. B5 proposed shared symmetric-residual/antisymmetric-contrast predictor. B6 one centralized repeated-call agent or deterministic controller with the same information/tools/candidates, full history, prompt-tuning budget and invocation allowance as the two specialists. B7 centralized code with the identical B5 representation/arbiter is an equivalence control, expected equal decisions. Generic “agents win” is not a hypothesis unless B6 fails fairly.

A faithful AgenticPD reproduction (S03 v3, S04 code) is a broader-system reference if its action surface can be matched; otherwise report its larger action surface explicitly, not a local causal comparator. HyPAS and full S08 should be compared faithfully if inputs/resources permit; a restricted reimplementation must be named adaptation. B0/B1/B2/B3 are mandatory even if an original implementation is unavailable. Original-method novelty audit remains independently blocking.

## Data and leakage

No dataset was acquired. Initial source candidates are rights-audited ORFS designs and public contest inputs. CircuitNet snapshots are not paired action-order labels; existing data may supply pretraining only with actual rights and cost logs. Split by underlying RTL/design family before checkpoint generation; variants, seeds, clocks and placements of one family remain together. No tuning on held-out outcomes. First feasibility pilot request: at least six rights-audited families, 3 training/1 validation/2 test, two fixed checkpoints each. This is an incidence and engineering pilot, insufficient for broad confirmatory generalization. Expand only with new allocation and preregistered sample size. Group LLM-pretraining/public-benchmark exposure as unknown; causal frozen-candidate tests reduce proposal-generation confounding but do not prove unseen pretraining.

For K=4 per specialist, ≤16 distinct cross pairs. A full label checkpoint requires at most 1 baseline + 8 singleton + 32 two-order state evaluations = 41 whole-state GR/STA evaluations; each pair order uses two primitive applications/legalizations. Deduplicate identical singleton/checkpoint evaluations by state hash for all arms and charge cache construction. Across 12 checkpoints the cap is 492 state evaluations, plus restoration and ≤864 primitive action applications if order prefixes are recomputed (8+64=72/checkpoint). This is an upper-bound ledger, not runtime or allocation. FAIL may terminate a branch earlier. These labels may already be too expensive; EXP-003 starts with at most 2 checkpoints and 4 pairs each (≤13 states/checkpoint) and stops before full generation if no useful contrast appears.

## Models, budgets and attribution

Proposed tiny CPU models first: GBDT and ≤100k-parameter MLP, three training seeds, ≤12 validation configurations total per architecture. No GPUs or external model APIs needed for this initial representation test. CPU limits and elapsed feasibility must be calibrated by an allocated preflight; currently unknown. Feature selection, all training/labels, hyperparameter search, model and token calls, communication, bad edits, cache, rollback, fallback and final suffix enter the ledger. Report cold-start cost and amortized cost for declared reuse count N. No online fine tuning on test data. If online updates are later allowed, all arms receive the same stream and charged adaptation cap.

Mechanism tests: zero contrast by prediction ablation; order-label shuffling; direct same-data model; swap-consistency; physically disjoint negative-control pairs; same-state repeat runs; realized-support versus intent-only features with only deployable initial features; training-label learning curves; central B7 identity; fixed-proposal versus end-to-end agents. Future realized support is a label/diagnostic, never an input to an unexecuted branch. Strongest alternative: ordinary joint learning learns all relevant contrast with no specialized target.

## Statistics, stopping and resources

Measure repeated baseline noise before defining contrast tolerances. Analyze paired design-family differences and bootstrap at the family level; report every failed/censored run. Two held-out families do not justify population significance. A subsequent confirmatory sample size needs pilot variance, engineering thresholds, actual rights/resources and fresh dual consent. Stop if exact prior overlap is found, adapter restore fails, order effects are below noise, hidden future inputs are required, direct/serial methods dominate, or final-route/cost losses erase the effect. Do not train a larger model to hide a failed incidence test. Any changed anchor uses a new topic; task edits invalidate consents.

Executable procedures and producer/consumer artifacts are in tasklist.md. No new experiments begin under this release. The actor owns no new allocation; no consent is issued. The batch stops after cycle four independently of the conditional tasks.
