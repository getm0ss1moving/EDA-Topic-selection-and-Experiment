# Experiment plan: EDA-0009 B4-R1

Research status: source/analytic stage only. Actual allocation null, execution gate CLOSED. The executable dependency/procedure authority is tasklist.md; this document states the comparisons and interpretation.

## Primary causal question

Holding checkpoint, fixed repair pool, exact cache/oracle and total budget constant, does a slot-conditioned acquisition representation buy useful verified route-closure progress after all discovery and fallback costs? The elementary support bound is a screening tool; a lower count of context intersections is not the endpoint. Measure residual sharing beyond identical K0, never raw overlap. Complete-warm, partial-warm and cold caches are separate paid regimes.

No learned arm is implemented or trained here. Capacity/configuration needs a later frozen manifest before agreement. Agent variants are optional delivery wrappers with identical observations/calls and a deterministic arbiter, not extra scientific seats; extra agents are not a novelty claim.

## Correctness and integration

Every complete candidate must match the named pinned reference's entire canonical marker/source tuples and connectivity, including removal/regeneration and unaffected baseline markers. Source inspection has not established clean certificate extraction or arbitrary selective-rule replay. EXP-102 is therefore a blocking engineering gate. Unsupported rules/configurations require complete reference work or UNKNOWN. If all candidates still need an unconditional full pass that makes the reused work redundant, charge both and report no check savings. The final selected state always pays full named-oracle reporting, independent connectivity, extraction and timing. Minimum-area gating in one inspected source path is a warning to inventory coverage; it is not a claim of all-rule completeness or an engine bug.

## Data, cost and inference

Freeze source/config/procedure hashes before candidate generation and record actual design/checkpoint/output hashes when generated. Fixed deterministic pools must include no-overlap, invalid, censored and failed cases. Separate independent design families before training/test; all related variants/checkpoints stay together. No final-route or secretly precomputed key is a free feature. Record every acquired payload/result mask and its source state. Query enumeration, baseline coverage certificates, serialization, invalidation, hashing/byte comparison, estimator inference, exact checks, fallback, final oracle, extraction and agent/token communication all count. Costs of collecting training labels are separate and reported, never hidden in deployment time.

Endpoint thresholds are unresolved, to be preregistered using independent calibration/user evidence in EXP-106. The project brief's D04 slack thresholds are provisional screening criteria for PPA improvements; no arbitrary transfer to a checking-time experiment is assumed. Report time-to-complete-target with censoring and best complete result at deadline. Pair candidate success is correlated; real utility must be observed or directly estimated, not assigned the old independent-success toy formula.

## Decision boundaries

H1: the proposed acquisition/representation improves the held-out complete-result time/quality frontier over C after total charges. H0 includes identical common-kernel behavior; no residual sharing; cost dominance by context construction/full fallback; ordinary factorization sufficiency; miscalibration/negative transfer; and DRC validation not being the practical bottleneck. A failed conditional regime is not a proof against all hybrid learning. One false certified output stops exactness; matching strong baseline defeats the claimed new mechanism; missing resources blocks readiness but does not disprove the hypothesis. Numeric effect/uncertainty forecasts remain null.
