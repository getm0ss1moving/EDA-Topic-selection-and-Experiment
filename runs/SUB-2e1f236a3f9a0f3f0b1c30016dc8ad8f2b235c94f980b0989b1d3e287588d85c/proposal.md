## New bounded scientific progress

CLM-B4-001 (elementary conditional lemma): Let a complete deterministic obligation record q contain a slot h plus its full context. A slot identifies the rule/version, target/source identity and geometry, layer/net labels and query definition. There is at most one complete record per slot per candidate state. Slot equality is only a projection; it does **not** establish record equality. A complete-context record includes the complete spatial-query result, including the empty result, query bounds, relevant derived data and all global semantic configuration. Hashes index payloads; equality compares canonical bytes. Any marker result includes stable source identities and all output data needed by the oracle.

Let Q0 be all supported records at the common checkpoint and Q_i all supported records at sibling i. In the complete warm regime K0=Q0, define R_i=Q_i minus K0. Construct an influence-support superset E_i of candidate slots whose complete record could differ from Q0 or be newly introduced. For finite-radius rules, E_i includes every new/changed anchor and every current anchor whose complete closed query intersects **either old or new** changed geometry. Connectivity relabeling, transforms, technology/rule changes, derived geometry and global options either propagate into E_i through audited dependencies or force E_i to all slots/UNKNOWN. Object membership returned by the old query is insufficient: insertion into an empty range is an invalidator.

For any shared residual record q in R_i intersect R_j, its slot is in E_i intersect E_j. Proof: if its slot were outside E_i, the complete unchanged record would be in Q0 and hence K0, contradicting residual membership; similarly for j. Therefore disjoint supports imply zero residual sharing. With one record per slot per state and nonnegative per-slot cost upper bounds u_h, weighted shared residual work is at most U_ij=sum over h in E_i intersect E_j of u_h. Slot splitting must retain the one-record invariant or multiply by an audited multiplicity bound. This is a necessary-condition screen and work-accounting lemma, not novel general optimization mathematics, a physical incidence measurement, or a wall-time bound.

A complete warm cache is a **conditional regime**, not a free byproduct of a marker report. Cold K0=empty invalidates the influence-only screen: unchanged records may be shared. A partial cache requires adding every potentially uncovered baseline slot to each appropriate E_i; when coverage cannot be proven, use all slots/UNKNOWN. Lower overhead cannot be obtained by silently pretending the baseline certified clean obligations. The deployed adapter must price the coverage ledger and any additional enumeration.

CLM-B4-002 (own model observations): The public code/stdout in search-log.md checks the residual identity and support inclusion in 1,500 seeded toy sibling pairs, including insert/delete/move/relabel/rule-version changes. Eight separated edits produce 28 pairs with six raw common records each but zero residual sharing and zero support intersection. A positive pair has six raw common records but one residual common record: four separate residual units versus three shared units. The model also exposes an empty-range insertion changing a clean result to a violation. These are generated 1D fixtures, not physical layout measurements or an OpenROAD defect report. All selected-candidate exact checks and their payloads remain necessary; avoiding 28 cross-candidate intersection comparisons is not avoiding 28 physical DRC calls.

## Concrete mechanism: jointly acquire residual incidence, then use the shared pair kernel

The candidate is a **slot-conditioned acquisition controller**, not a renamed pair policy. Its deployable inputs are the common checkpoint, actual candidate deltas, rule inventory, baseline coverage ledger and charged support synopsis. Candidate generation remains fixed. Exact alternative-state query payloads and outcomes are hidden until their materialization/checking is paid for.

1. Build E_i and conservative U_ij for the supported subset. Unsupported dependencies yield UNKNOWN and complete reference fallback. The screen may mark an edge NO_NEW_SHARING only under its stated complete-coverage assumptions. It never certifies rule cleanliness or removes a candidate solely because sharing is absent.
2. Form a bipartite graph of candidate IDs and slot IDs. Each candidate-slot node contains deployable rule/layer/anchor geometry, actual edit summary, baseline-certified/unknown flag and support membership. No final-route labels or hidden post-candidate context are allowed as free features.
3. The explicit estimator hypothesis factorizes residual incidence by slot. A shared slot encoder pools observed candidate-slot contexts and masks; candidate-specific heads estimate candidate completion value, isolated work and pair residual saving. An acquisition head scores a **slot group query**: materialize that slot's full payload in the competing candidate states, compare to K0 and one another, and update every affected pair estimate. A query has a returned key/output mask, charged CPU/bytes/time, and candidate-state hash. Predicted sharing is bounded by a valid U_ij when available; otherwise it is only a prediction. Joint success is predicted directly or by a joint head; no independence assumption for real repair outcomes is imposed.
4. At each step enumerate all singletons/pairs with the common kernel. Compute expected terminal value under the current estimates, including already spent discovery and estimated full check/fallback costs. For each available slot-group acquisition a, estimate the expected change in best feasible terminal value after its observation, minus its acquisition charge. Query the highest positive value, deterministic slot-ID ties, while the reserved deadline permits; otherwise stop acquiring and choose the current best estimated feasible subset. An operation deadline is enforced independently of prediction. Aborted or incompletely checked candidates get no verified-success credit.
5. Materialized keys may inform scheduling and exact reuse only if the payload and scope contracts hold. Every selected candidate must finish the supported exact work, unsupported-rule reference work, marker regeneration/removal and independent connectivity guard. Final selected state receives the fully charged whole-design reference report and extracted timing checks.

The acquisition value calculation may use a finite ensemble of bounded outcomes from an identically budgeted fitted model, with every inference charged. Before any model evaluation, freeze ensemble size/configuration, calibration procedure and feature schema in EXP-104. No model training, learned acquisition, physical adapter or controller has run in this job. The proposed representation makes one acquired local context visible to several competing pairs; a separate pair predictor lacks that hard-wired sharing. Whether this helps beyond a conventional factorized model or shared-trunk network is unresolved, not asserted.

Primary comparisons are nonlearned support-gated lazy acquisition; conventional lazy acquisition with identical graph/bounds/tools; same-feature separate pair predictors plus fusion; equal-budget shared-trunk multitask model; direct set-value/acquisition model; and the proposed slot-conditioned factorization.
