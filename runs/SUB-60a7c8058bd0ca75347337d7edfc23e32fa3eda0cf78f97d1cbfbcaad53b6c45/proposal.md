## CT01: exact selection reduction and policy mapping

Let H be the frozen directed cost-expanded target graph. State x=(routing vertex, integer cost consumed); e has all-disabling-owner label L(e), with hard obstructions removed. For release S, e is usable exactly when L(e) is a subset of S. Connect all eligible terminal cost states to one label-free sink. Subdivide each directed e=(x,y) into x -> z_e -> y and put L(e) on z_e. A path is enabled iff the union of its labels is a subset of S. Thus minimizing distinct released owners for target reachability is precisely the discrete MCR objective, with direction and cost-state semantics retained. S20 Section 3.2 supplies subset-state search; S21 Problem Setup directly labels edges. The reduction is our explicit derivation, not a physical-delay theorem.

## Concrete mechanism repair, preserving the anchor

1. Freeze an incumbent and clip before comparing policies. Select a constrained violating setup endpoint, its interconnect and fixed pin/boundary connections. Expose at most 32 eligible signal owners; exclude immutable clocks, power and fixed obstructions. Record owner-pool construction and counts before candidate outcomes.
2. Build H once per fixed transaction context using all-owner disabling footprints and fixed nonnegative weights. Proposed deterministic quantization: at most 128 cost states; q(e)=ceil(w(e)/delta), budget Q=floor(B/delta), delta and B selected only on development input. Zero-cost arcs need visited-state deduplication. Overrounding can discard physically good routes; fail-closed graph reachability is not physical infeasibility. Rule/context absent from the graph cannot justify a certificate.
3. For a target-unreachable release R, compute U=reachable(H_R,s). For each non-hard edge in the outgoing frontier record L(e), graph hash and U hash. Every feasible release S must satisfy C_U(S)=OR over frontier edges of [L(e) subset S]. The collection Phi=AND of learned C_U is only a necessary target-reachability condition. M tests these clauses to skip owner sets, recomputes reachability for survivors and records every pruning reason. A cut cannot reject an S that enables one of its complete frontier labels. Hard-only frontier rules out target reachability only in this fixed H.
4. Enumerate the same predeclared owner subsets of size <=3 used by B3/B4, in cardinality then immutable owner-ID order; M removes only sets failing a valid clause. At most 256 distinct considered owner subsets and 50,000 total expanded search states per arm/trial; clause/dominance work and preprocessing are charged in the same time budget. An arm stops at the first budget/candidate/state/RSS cap; incomplete search is censored. The exact counting schema is in experiment-plan.md and must be code-pinned at T04.
5. **Do not prune useful supersets merely because target reachability was already obtained.** Rebuild the target and released owners jointly with common fixed path-generator limits, all pin/boundary stubs and compatibility rules. Each released owner may retain its incumbent path as an option. For each subset, use the same reconstruction candidate order in every arm. No method receives a free oracle or a private enlarged clip. ## CT03: acceptance limitation and demand denominator

For independent endpoint slacks (-0.10,-0.10) ns and disjoint permitted clips, a repair that changes only one value to -0.05 leaves the minimum -0.10. Each first move is rejected. The two simultaneous repairs would yield -0.05 but are outside this single-clip transaction. For a unique worst endpoint s1 and an unaffected second worst s2>s1, any local improvement has WNS gain at most s2-s1. Thus, if s2-s1 is below the meaningful-effect threshold, even a perfect target repair cannot pass that threshold unless it also affects the second endpoint. This is a conditional derivation, not a frequency measurement or a global physical bound.

No engineer-supported exclusion of tied cases has been established. We preserve strict whole-design acceptance, explicitly record this limitation and require an all-case denominator rather than declaring such cases irrelevant. T02/T07 record total preselected DRC-clean checkpoints; setup-failing checkpoints; all constrained endpoints; selected clips; tie/near-worst endpoints and conservative off-clip influence unknowns; target-reachable releases; joint-feasible candidates; accepted changes; threshold passes. The off-clip screen is descriptive unless no influence is proven; full STA remains decisive. Failure/zero/ineligible cases remain in per-design all-case results. Useful conditional success alone cannot establish broad engineering demand.

## CLM-016: rehoming-owner fixture and fair comparator repair

Analytic finite-resource fixture: target A has incumbent detour d (cost 10) or preferred corridor x (cost 1). Owner B occupies x and may move only to corridor y. Owner C occupies y and may move only to z. All corridors have capacity one; endpoints and other resources are private; target surrogate budget is 2. The target's preferred path has label {B}. Release {B} makes it target-reachable, but B cannot be embedded while C retains y. Release {B,C} permits A->x, B->y, C->z. C does not label the target path. This is a thought construction, not measured geometry or extracted timing; it is already the kind of resource interaction concurrent routing can handle.

Consequently B4's target-only label dominance is valid inside its MCR search but cannot be interpreted as a physical superset-pruning certificate. B4 emits distinct nondominated target-label seeds and uses the common bounded superset-completion schedule over the full owner pool; it does not stop after its first minimum target cover. M and B3 use that same owner universe and reconstruction. Candidate duplicates count once for reconstruction, while all generation/dominance/duplicate-handling time is charged. On tiny exact checks enumerate all permitted supersets. If a standard MCR-plus-common-reconstruction composition matches M, reject the contribution claim. This repair clarifies the original atomic reembedding requirement; it does not establish new interaction novelty.
