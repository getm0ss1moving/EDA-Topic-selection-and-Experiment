# Conditional experiment plan

## Authorization and registration

This plan is written, not executed. Source inspection, symbolic reasoning and release validation are the only work performed. S00 records provisional caps, not a new resource allocation. Require both exact-revision task-list consents and verifier readiness before any physical experiment. T03 must explicitly record an actual compute allocation; none is assumed from this document.

## EXP-001: policy distinction and graph correctness

Purpose: falsify CLM-010 before router integration. Generate deterministic small layered graphs with 2–4 nets, hard obstacles, shared disabling-owner sets, fixed boundary stubs and bounded additive costs. Include the A/B example, no-headroom cases, two-owner-disabled edges, nested cuts, owner relocation causing a new blockage, insufficient clip, non-additive physical-delay counterexamples and discretization edge cases. Exhaustively enumerate route assignments only on these small graphs to obtain an exact oracle for that graph model. Compare critical-only, geometric blocker, cut-disabled cardinality enumeration and cut-guided selection using the identical path generator, owner cap and total state-expansion allowance. A novel solver is not established merely by solving the two-net example.

Artifacts: generator source/config hashes, complete instance seeds, exact graph-optimum assignments, each cut and owner map, pruned-set trace, failure reasons, operation counts, runtime and peak RSS. Every reported infeasibility must state the clip, discretization and exhaustive cap. A false impossibility certificate fails correctness. Cases beyond a cap are censored, never counted infeasible. Success is necessary but insufficient for physical utility. T01 must compare with existing minimum-label-path, hitting-set, flow and rip-up formulations before interpreting any improvement as scientific novelty.

## EXP-002: fixed-design downstream timing test

Data prerequisite: three independently selected, legally usable standard-cell designs at the pinned Nangate45 typical setup; GCD is integration smoke only. T02 preselects by license, diversity and bounded size before method outcomes. Candidate names can be aes, ibex and jpeg from accessible public flow fixtures, but these are not yet acquired, pinned, licensed or declared representative in this job. Resolve actual versions and access first. Macro-rich data is not required by this narrowed scope and no macro result is claimed.

Prepare exactly one fixed post-route checkpoint for each design/paired seed. No candidate changes netlist, cell location/type, clock routes, SDC, PDK, corner, extraction rules or die. Expose seeds 0–4 through an instrumented, proven effective branch; record queue order hashes and identical base checkpoint hashes across arms. If the pinned flow is deterministic regardless of those seeds, do not pretend five duplicates are independent: use prespecified controlled order perturbations and document the experiment change before consensus.

Five arms: B0 unmodified incumbent plus a matched no-op extraction/STA; B1 target-only bounded reroute; B2 criticality-first plus geometric-blocker joint repair; B3 same joint engine and owner pool with cut-disabled cardinality/lexicographic selection; M full cut-guided release. B2/B3 receive the same clip envelope, owner/candidate cap and overall CPU/wall budget as M. Retain the strongest applicable WXL/adaptive-region policy implementation in B2, with source/patch provenance. Any implementation mismatch blocks the comparison rather than being excused by a name. Newer optimizer policies from S08 are a sensitivity comparator only if reproduced affordably; unresolved inability limits generality.

Development: one separately designated fixture for choosing graph-cost bins, budget conversion and clips. Freeze configuration and patch hashes before opening test outcomes. No model training is required; no hidden tuning, route-search, failed compile or oracle cost is free. Define deterministic tie breaks and candidate ordering. The budget ends a trial, not the logging of a failure.

Oracle: full-design connectivity and DRC at pinned tool/rule scope; compare against baseline zero violations, not a relaxed new limit. Use unchanged extraction to produce SPEF and full OpenSTA setup/hold reports for all constrained endpoints. Record unconstrained endpoints and fail if coverage changes. No incremental-STA shortcut or surrogate acceptance. The integration task must establish concrete commands from pinned tool help/tests before execution; this release has not verified a command that can selectively reroute the proposed nets. Do not invent one. Power uses identical activity assumptions; report it explicitly as an estimate. Router-internal DRC is not foundry signoff; independent checker coverage is unresolved.

Provisional screen, from S00: +0.02 ns paired whole-design worst setup slack, no new hold-violating endpoint, no additional DRC/open/short, <=2% cell-area and estimated-power regression and <=20% total runtime regression. Netlist/placement identity makes cell-area change zero by construction; report wire/via area and counts separately. Thresholds must be validated/frozen at T02 before evaluation. Aggregate each design separately and report all 15 pairs, median and design-stratified uncertainty. Do not pool correlated seeds as 15 independent designs. With only three designs, label confidence intervals exploratory; report exact paired differences and failures. No selective omission of hard designs or seeds. Compare M to strongest B2/B3, not only B0.

Mechanism mediation: record how many M selections open the witnessed frontier, produce a compatible joint embedding and survive the full oracle. Interleave accepted/rejected candidate logs. If setup improves through unrelated cleanup, or cut-disabled selection performs equally, the mechanism claim is not supported. A route-cost improvement or lower HPWL alone is a failed utility result.

## Budget and stop rules

Current execution allowance: none newly granted. Conditional ceiling inherited from S00 is 8 CPU-hours total, 4 GB RSS, two CPUs, one physical job, no GPU, no new API spend. Include builds, input preparation, all baselines, rejected search, oracle and analysis. Resource inventory precedes scheduling. Five arms × three designs × five seeds = 75 complete evaluations, before development overhead. At 600 CPU-seconds each, that is 12.5 CPU-hours; thus the design is not promised to fit. At 2 busy CPUs, 600 wall-seconds means 1200 CPU-seconds, not 600. T03 must estimate charged CPU-seconds from separately authorized calibration and a safety factor; if the envelope cannot support the fixed minimum comparison, mark infeasible or request a new owner allocation without silently dropping controls. This batch authorizes no such calibration.

Per local trial proposed hard limits: 32 exposed owners, 3 released blockers, 256 owner subsets, 50,000 expanded states and <=128 bins; clip-edge overflow or unsupported rule means fail-closed rollback. Numerical tolerances, clip dimensions and route-cost scale remain T04 specifications, so reproducible readiness is false. Do not execute with guessed values. Entire-topic kills: confirmed equivalence, graph-certificate error, no qualifying failures, no gain versus equal-budget strongest baseline, any new correctness failure, or inability to satisfy both validity and resource constraints.
