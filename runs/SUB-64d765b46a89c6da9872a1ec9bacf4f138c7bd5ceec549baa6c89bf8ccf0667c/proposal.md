## Mechanism: verified operation-specific partitions

For primitive operation v and world w let x(v,w)=F_v(theta(v,w), parent values). Its key K(v,w) comprises operation/code version, exact parameters, analysis tags, relevant electrical/RC/library/SDC epochs and the complete parent values read by that operation. Hashes are indexes; full key equality is checked before reuse. Include floating bit patterns/rounding behavior, statuses and exception semantics. NaN or unsupported nondeterministic state returns UNKNOWN/fallback. A learned embedding or rounded state never establishes equivalence.

Represent the worlds at each operation as classes of equal complete keys, with an immutable representative result and a world membership set. Partition intersections combine parent classes and the local edit-support partition. Evaluate one representative per key, attach its value to every member, then coalesce equal RESULTS for successors. Delay operations may have a different key from arrival operations: a shared delay does not imply equal arrivals. Forward and backward phases require separate complete dependency schemas; neither may inherit another phase's equality. A new accepted base starts a new epoch; invalidate conservatively. The initial implementation is conservative exact equality; any context-reduction theorem would need a new explicit proof and independent review.

A topological induction proves equality to independent evaluation of THIS pure deterministic graph: equal keys imply equal primitive output; each world's parents are reference-equal by induction; expanding the class value therefore reproduces its reference value. Finite graph traversal terminates. This is a straightforward consistency argument, not a new STA theorem. It says nothing about an unextracted engine's hidden state.

## Analytical progress and a limiting reduction

Own A01 arithmetic used a three-operation DAG u,r,z over four integer-valued worlds. With dominating reconvergence the serial evaluator used12 primitive calls; exact global keyed cache and partitions each used9. Without reconvergence each used12. For n=1 all used3. Across512 ordered tiny cases, outputs and memo/partition primitive counts matched. These are dimensionless operation counts, NOT timing-flow runtime or physical measurements.

For any fixed pure graph, fixed requested worlds, cold exact caches of sufficient capacity, and identical complete keys, an ordinary global memoizer evaluates exactly the same unique keys as this partition construction. Neither can claim fewer primitive calls than the other solely from its representation. A predictor cannot change that count just by reordering work. This self-initiated reduction is part of the current proposal; the hypothesis survives only as an unmeasured administration/memory tradeoff.

Incomplete-key counterexample: equal arrival5 with slews1/2, next arrival A+S, gives6/7. Arrival-only merging is unsound. Rounded arrival0.999/1.001 with requirement1 rounds to the same0.01 bucket but gives opposite slack signs. Exact input equality, not approximate closeness, is required. Full script, results and hashes are in experiment-plan.md:A01.

Let n_v be independently recomputed world instances after the SAME baseline incrementality, u_v their distinct exact keys, and t_v primitive cost. Let A_s/A_m/A_p be total administration for serial/memo/partition methods, P predictor/communication cost, and R all reporting/restore/fallback costs (method-specific differences must be included, not assumed equal). In the simplified common-R case:

T_s=sum(n_v*t_v)+A_s+R;
T_m=sum(u_v*t_v)+A_m+R;
T_p=sum(u_v*t_v)+A_p+P+R.

Partition wins over strong memoization only if A_p+P<A_m; against serial it additionally has sum((n_v-u_v)*t_v) available. No reuse means u_v=n_v. n=1 and positive net extra administration lose. With finite memory, recomputation depends on schedule/eviction, so record an explicit trace, byte cap and policies. An offline optimum is a diagnostic bound only; do not grant future test-trace knowledge to a deployable predictor. Complete explicit output serialization remains Omega(total requested output entries); internal sharing cannot remove it.
