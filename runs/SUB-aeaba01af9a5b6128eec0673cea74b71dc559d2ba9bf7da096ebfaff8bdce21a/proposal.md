## Problem and engineering decision

A digital physical-design engineer closing detailed-route geometric violations must decide which already generated local repair candidates deserve exact checking before a fixed closure deadline. Repairing a target marker can change neighboring obligations. The proposed decision is which small subset of sibling candidates, starting from the same canonical routed checkpoint, to validate and in which order. The downstream endpoint is time to a complete, connected, engine-DRC-clean routed design with preserved post-route timing/area guardrails; predicted marker reduction or cache-hit rate alone cannot establish utility.

The new causal question is whether candidate selection should price the **shared future exact-check work** across alternatives, rather than independently scoring each candidate's immediate benefit and isolated checking cost. The candidate pool and checker are held fixed. Context-complete exact-result reuse is infrastructure, not claimed new science. The potentially useful contribution is feeding the geometry/rule-conditioned obligation-sharing structure back into a bounded two-candidate selector, including the cost of discovering and maintaining that structure. A shared predictor of repair benefit and obligation overlap is one hypothesis, not the default winner. Broad repetitive checking demand is supported by S01/S03/S08a/S08b; the frequency and economic value of cross-candidate reuse in this digital route setting remain unknown (CLM-007).

## Mechanism and formal contract

For candidate c at checkpoint s let Q(c,s) be its complete canonical set of supported rule obligations. An obligation key contains the rule-deck/version identifier, predicate semantics, target geometry, relevant net/layer labels, full current spatial-query result including negative/empty-range information, hierarchy transforms and all declared derived inputs. Hash equality is an index only; canonical payload equality must be checked to avoid relying on collision freedom. Geometry changes invalidate range queries even if every previously returned object is unchanged. Deleted shapes, inserted shapes, connectivity relabeling, rule changes and grid/boundary cases are explicit invalidators. Marker regeneration/removal is part of the obligation result. No geometric normalization other than proven semantics-preserving operations is allowed.

A certificate records a deterministic checker result for that full payload. For a *complete enumerator* and unchanged payload, reusing the result is equivalent to re-evaluating the predicate. This is an elementary deterministic-function argument, not a new theorem and not proof the physical adapter is complete. Enumeration, context hashing, deserialization, memory pressure, invalidation, proof checks and final full fallback all consume budget. Skipping an unknown obligation never certifies success.

Let K be the currently valid cache, w(q) measured check cost, and B the remaining wall-time budget. For a fixed selected candidate set T the idealized non-evicting reusable work is

    W(T | K) = sum_{q in union_{c in T} Q(c,s) minus K} w(q).

Different candidate states share a key only if their full rule-context payloads really agree. The physical model must not substitute object IDs or old-neighbor lists for context equality. W is an offline accounting model; future Q, costs and benefits are not magically free deployable observations. The controller must use current metadata or charged predictions and exact incremental discoveries. The primary bounded controller enumerates singletons and pairs (at most 136 nonempty sets for 16 candidates), estimates terminal verified repair value under total cost, and evaluates the chosen feasible set. It re-evaluates its ranking after actual checked information, with deterministic ID ties and a charged hard deadline. No result is credited before its full oracle and connectivity obligations complete. A full-layout fallback is required whenever the restricted proof obligation is incomplete.

**CLM-009 negative control:** for a fixed complete candidate pool, unlimited non-evicting cache, deterministic fixed costs and mandatory completion of every candidate, total unique work is the union above and is independent of order. Scheduling has no reduction to claim in that regime. Benefit requires budgeted subset selection, early stopping, capacity effects or adaptive generation. The initial anchor uses budgeted subset selection only; finite-cache eviction and adaptive generation are robustness tests, not hidden sources of gain.

## Three innovation lenses and fair alternatives

1. **Cooperating algorithmic agents:** a repair proposer exposes candidate patches; a verification specialist exposes exact/predicted obligation footprints; a single deterministic arbiter chooses work and serializes state writes. Messages are typed state-hash/candidate/rule/payload identifiers with version checks. Both specialists observe the same released algorithmic design state; they cannot certify an unchecked candidate. Termination is deadline, exhausted pool or a fully checked target. A centralized controller with identical information and calls must match this behavior; separate agents are not necessary. An optional LLM selector would receive the same candidates/features/history as a repeated-call single agent, with all tokens, failed calls and communication charged. None is executed here.
2. **Bounded unified prediction:** shared geometry/rule representation jointly predicts completion benefit, isolated check cost and pairwise reusable-work fraction. Compare same-feature separate predictors plus fusion, ordinary shared-trunk multitask prediction and a direct model predicting the terminal set value. Use held-out families, masked/censored labels and identical training/search budgets. A shared model is useful only if downstream verified decisions improve after its entire cost; loss reduction alone is insufficient. No accuracy or calibration guarantee is claimed.
3. **Prediction plus precise analysis:** any predictor schedules work only. Exact obligation validation and full fallback own acceptance. Compare nonlearned coverage-greedy and bounded beam controllers, fixed scheduling, a generic dynamic-dependency/memoization implementation and the exact same cache with a direct terminal-value model. The strongest routine composition may win. This lens currently has the clearest correctness specification, but no evidence selects it scientifically over the others.
