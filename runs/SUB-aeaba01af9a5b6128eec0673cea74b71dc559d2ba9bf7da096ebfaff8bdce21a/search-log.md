## Own analytical checks (not EDA)

Own root `analytic_check.py`, Python stdlib, deterministic seed 9009, less than one CPU-minute. Initial additive set-reward diagnostic was run once (4 vs 6, arbitrary units). Before freeze it was replaced with the terminal-success objective below: independent stipulated candidate probabilities 0.4/0.35/0.35, not empirical values. This makes the toy endpoint probability of at least one acceptable alternative, rather than mistaking summed candidate reward for best-candidate route quality. Both variants are synthetic analytical examples; only the final version supports the current proposal. It is NOT a trained predictor or a measurement of an EDA success probability. No independence assumption is imposed on real physical candidates; joint outcome dependence must be estimated/tested in future comparisons.

A/B/C obligation sets are A={a,b,c}, B={w,x,y,z}, C={w,x,y,q}; each new obligation costs one abstract work unit. At cap5 isolated ratio-greedy chooses A and cannot complete B/C; B+C costs5 and has stipulated independent success probability 1-(1-.35)^2=.5775. This is a construction showing a possible regime, not a new coverage algorithm or evidence its cost/benefit structure occurs in routing. With all candidates completed, unique work is8 in every permutation. The 1D predicate is distance<3 on integer points with distinct IDs, not a LEF rule implementation or foundry DRC model.

Final reproducible script (write to an own external scratch path, not the checkout; run `python3 analytic_check.py`):

```python
import itertools, json, random
rng=random.Random(9009)
def full(s):
    return sorted((min(i,j),max(i,j)) for i,x in s.items() for j,y in s.items() if i<j and abs(x-y)<3)
def update(old,new,old_markers):
    changed={i for i in old.keys()|new.keys() if old.get(i)!=new.get(i)}
    kept={tuple(v) for v in old_markers if not(set(v)&changed)}
    found={(min(i,j),max(i,j)) for i,x in new.items() for j,y in new.items() if i!=j and (i in changed or j in changed) and abs(x-y)<3}
    return sorted(kept|found)
n=0
for _ in range(300):
    old={i:rng.randrange(21) for i in range(rng.randrange(1,7))}
    new=dict(old)
    for __ in range(rng.randrange(1,4)):
        i=rng.randrange(8)
        if rng.random()<.25:new.pop(i,None)
        else:new[i]=rng.randrange(21)
    assert update(old,new,full(old))==full(new)
    n+=1
old={0:0,1:5}; new={**old,2:1}
assert full(old)==[] and full(new)==[(0,2)]
# Positive-object-only cache key sees no old neighbor change; range contents do.
def context(s):return tuple(sorted((i,x) for i,x in s.items() if abs(x-s[0])<3))
assert context(old)!=context(new)
keys={'A':set('abc'),'B':set('wxyz'),'C':set('wxyq')}
value={'A':.4,'B':.35,'C':.35}; cap=5
# No result is credited until every required key has been checked.
def evaluate(order):
    cache=set(); score=0; done=[]
    for a in order:
        need=keys[a]-cache
        if len(cache)+len(need)>cap:continue
        cache|=need;score=1-(1-score)*(1-value[a]);done.append(a)
    return round(score,12),len(cache),done
best=max((evaluate(p)[0],p,evaluate(p)) for p in itertools.permutations(keys))
greedy=['A','B','C']
assert evaluate(greedy)==(.4,3,['A']) and best[0]==.5775
unions={len(set().union(*(keys[k] for k in p))) for p in itertools.permutations(keys)}
assert unions=={8}
print(json.dumps({'synthetic_spacing_transitions_checked':n,'stale_positive_only_counterexample':{'before':full(old),'after':full(new)},'budget5_greedy':evaluate(greedy),'budget5_best':best,'all_candidates_unlimited_cache_unique_work':list(unions),'scope':'own toy predicates and unit-cost set scheduling; no EDA engine, training or physical incidence'},indent=2))
```
