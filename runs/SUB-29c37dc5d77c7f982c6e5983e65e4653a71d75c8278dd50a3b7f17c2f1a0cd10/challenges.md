## Correctness, headroom, cost and contest assessment

No new fatal correctness contradiction was found in the conditional lemma. Before an executable exactness claim, EXP-003/006 must also distinguish (a) a candidate absent from the dirty set and inheriting base state, (b) a dirty candidate producing the same output as base, and (c) a fallback candidate already partially processed. A reconvergent join must reconstruct every candidate once without dropping or duplicating it. Use differing pin caps, identical numeric outputs with different tags, unequal signed-zero records and partial-batch cap exhaustion. These are proposed checks, not observed failures.

Analytical bound (not measurement): if fraction f of B+ elapsed time is removable scheduling/key/copy work, fraction r of that work is actually removed, and added mask/replay/report cost is h times B+ time, then normalized candidate time is 1 - f*r + h, under this accounting partition. A 20% reduction requires f*r - h >= 0.20. Even total removal cannot achieve it if f < 0.20 and h >= 0. No value of f, r or h is available; this is not a saturation claim. The output lower bound applies only to outputs genuinely requested by the caller. Preserve cold/warm runs and equal memory budgets; charge repeated scalar replay, context checks, initialization, GC and full-context guard. Reference validation overhead should be separately visible from deployment-essential work, even if both are included in the overall research resource ledger.
