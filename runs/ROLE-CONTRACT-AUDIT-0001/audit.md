# Role contract audit

Scope: proposer/challenger contracts and dependent verifier, coordinator, evidence, isolation and promotion controls. Basis: the owner's original EDA research requirements and subsequent instructions reserving human review for final reports. This is coordinator governance work, not an independent scientific verdict.

| Requirement or gap | Resolution | Enforcement |
|---|---|---|
| Detailed subfield survey, papers/contests/open and closed tools | Explicit coverage and comparable-gap checklist | Proposer/challenger evidence; verifier semantic review |
| Avoid duplicate work and trivial combinations | Exact mechanism delta, naive-composition and ablation tests, contest overlap | Harness and eight existing acceptance gates |
| Structural innovation must serve engineering needs | User/decision/endpoint/constraints and evidence; unknown thresholds stay provisional | Harness and utility/feasibility review |
| Avoid speculative theoretical saturation | Applicable model/assumptions and counterexamples required | Evidence and challenger rules |
| Proposer must not obey unsupported challenges | Verifier-first response, appeals and objection withdrawal history | File workflow; semantic verification |
| Joint abandonment and new topic after dead end | Retained existing grounds and dual consent; signatures now bound to assigned dossier sessions | Validator and role contracts |
| Experiment task list must be agreed by both assigned roles | Reject substitute sessions and cross-topic session registration | Regression tests; plan dependency hashes checked by verifier |
| Human review only at final reports | Remove stale AI-as-GitHub-reviewer instructions; distinguish human and AI verification | Existing path gate; nested README bypass closed |
| Large PR file-list truncation could hide a final report | Fail closed to human review when changed-file count exceeds returned files | GitHub API-based workflow |
| Forecast leaks beyond forecast.json | Semantic redaction log and hashed initial packet; disclose accidental exposure | Coordinator release duty; not claimed as automated |
| A merged harness does not update running roles | Hashed policy amendment and actor receipt required | Coordinator procedure; no frozen packet mutation |
| Resource ceiling mistaken for allocation; preparation mistaken for experiment | Explicit scoped authorization and cost records | Experimental contract; job labels alone are insufficient |
| Coordinator inventing owner answers | Separate owner instruction, coordinator suggestion and unresolved question | Evidence standard |

Residual limits: text rules cannot prove novelty, market need, truthful citations, enforce independent thought, or prevent an administrator changing GitHub settings. Existing packets retain their original hashes and must receive amendments before these new rules govern their next round. No private role memory or transcript was read, no scientific verdict was issued, and no candidate's claims were edited. Exhaustiveness of all possible future loopholes is not claimed.

Validation: repository structural validation, full unit suite, and diff whitespace checks. Input commit is recorded in manifest.json.
