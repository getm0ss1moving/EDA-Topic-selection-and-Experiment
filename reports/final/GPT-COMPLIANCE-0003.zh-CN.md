# D04 / D05 新增四轮：选题与角色审计报告

本批已完成 D04、D05 各四个新增回路，共 24 份有效科学角色交付、8 份独立规范审计；8 个逐轮 PR 已合并。两个方向均在四轮上限停止，没有启动第五轮。四个被研究的题目均停放，没有确认可执行选题、共同弃用签署或启动新的物理实验。协调者负责汇总与传输，科学裁定属于每轮独立 verifier。

## 范围与证据边界

本批延续 GPT-INNOVATION-0002，另做 D04、D05 各四个完整 proposer → challenger → verifier 回路，每个回路再由新会话的 verifier 审计三位科学角色。提出者使用 gpt-6.1-sol/high，质疑者使用 gpt-6-astra/low，科学核验与规范审计使用 gpt-6.1-sol/low。这些是记录的请求配置；未另行取得底层模型的独立证明。

各角色只通过分配的冻结文件交换研究内容。它们可独立检索外部研究，不能读取其他角色的私有笔记、对话、记忆或未释放材料。全部研究交付物为英文，本报告面向项目所有者使用中文。

本批授权的是检索、推导与轻量自编算例，未新增 EDA 构建、物理流程、训练、远程算力或付费 API 实验配额。合成算例的数字不是芯片测量值；没有校准依据的性能与成功概率预测保持 null。共享操作系统及自述活动表不构成强隔离，也不能证明不存在未披露行为。

## D04 原题 EDA-0008：有条件的顺序效应预测

原题研究 pre-CTS 阶段的两种固定物理操作：单元尺寸调整与另一单元的绝对位置移动。它尝试用共同项和顺序对比项预测两种执行次序的结果，并最终以详细布线后的质量和完整成本评价。坐标变换本身可逆，不能当作新的表示能力或创新；后续明确的低秩限制才形成可证伪的假设。

三轮新增研究得到以下经过科学核验的推进：

- 把操作成功与部分可观测情况写清，区分九种语法成功掩码及 49 种逐指标观测子掩码。它们是定义空间，不证明真实设计中都会出现。
- 修正带权重的变换损失，保留交叉项和单操作参考误差；将等价直接实现作为必须相等的控制组。
- 识别回滚后仍可能保留决策相关历史的源码路径，把参考执行改为独立进程及独立可变目录，并把初始化与恢复成本计入。
- 明确低秩模型的张量、参数和反例，要求比较强直接模型、普通低秩模型、原生流程和联合传统优化方法。
- 增加与决策边际、平局、次序翻转和实际后悔值相关的诊断，避免用低矩阵误差替代工程收益。
- 要求最终合法性、等价性、报告与导出文件绑定同一个最终设计状态。源码中的重试流程说明这一适配器检查有必要，尚未观察到实际运行错误。

第三轮决定为 **park**：物理顺序效应的频率、低秩归纳偏置的真实价值、传统联合对照的忠实实现、最终布线收益、原始获奖方法覆盖和实际资源准备仍未闭合。原题未被判为普遍无意义，也没有形成共同弃用签署。

若重开，先锁定工具、设计、PDK/库、SDC、corner、资源、主要指标和有意义效果阈值；再验证干净执行及最终状态 oracle；随后才是有上限的效应普查、同信息/同成本模型对照与最终布线评价。所有执行阶段需要精确 tasklist 的独立一致签署。若顺序效应低于重复噪声、普通方法已取得相同成本前沿，或进程/标签/回退成本抵消收益，应保留负结果并停止该机制。

## D05 原题 EDA-0007：电气相关性与精确测量的选择

原题在同 footprint/VT 的替换候选之间，用有物理含义的电气对比特征构造联合预测，选择值得执行精确测量的候选；最终只返回已测量且满足 guard 的结果。研究贡献必须来自物理特征、校准和完整系统的有用权衡，不能来自 GP、相关性或前瞻策略的名称。

三轮新增研究澄清了四个决定性边界：

- 单步期望后悔下降在所列条件下化为联合 constrained EI，不能另加一个被重复计算的信息收益；同均值、同协方差的 GP 是完全等价控制。
- D 表示每个索引上持续存在的潜在差异，不能伪装成每次查询重新产生的噪声。精确观测后，已观测输出的后验方差为零。
- 已知模型、两维潜变量、D=0、每个完整观测块可逆且两次等成本查询时，第一次查询已识别整个表，第二次测量最佳剩余候选即可达到该局部目标；这不是物理时序优化的普遍上限。
- 混合秩高斯合成例子能体现信息迁移，但任意非零的满秩扰动在上述理想条件下可使其前瞻优势消失。引入持续差异后，rho/epsilon² 解释观测信息的尺度关系；它仍不证明真实电路的决策收益。

第三轮还加入了“信息下降但所有候选收益均为零”的负控制，以及 n、k、测量成本 t 和额外开销 H 的完整账本。在等事务成本模型中，净节省需要 `(n-k)t > H`；候选少或必须全测时，调度本身可以增加成本。不能只选有大候选池的样本来证明有用。

第三轮决定同样为 **park**。重开需要代表性候选数量与成本分布、完整恢复和测量适配器、实际电气残差、强均值校准及同特征控制、局部目标与最终全局 guard 的联系、原始获奖方法覆盖和真实配额。下一阶段应先做有上限的成本/残差诊断，再决定是否值得训练和完整流程实验。现有证据不能给出可靠的物理加速比、PPA 提升范围或论文成功概率。

### D04 / EDA-0009：面向详细布线修复的共享精确检查成本选择

工程问题是在固定时间内，选择哪些局部布线修复候选值得完成精确检查。提案保持候选生成器与检查器相同，尝试把候选间共享的几何/规则检查义务纳入选择，而不只看单个候选的收益和独立检查成本。多 agent、联合预测和预测加精确检查均作为可比较的实现，集中式同信息基线必须保留；agent 数量、缓存或哈希本身不是创新。

独立科学核验支持两项阻断推进、但可修复的质疑：

1. **只计算共同基线之外的新共享工作。** 若 K0 已经缓存共同检查点的合法证据，候选 i、j 的剩余义务是 `R_i = Q_i \ K0`。成对共享节省由 `R_i ∩ R_j` 决定，原始 `Q_i ∩ Q_j` 的巨大重叠可能不产生任何新增收益。K0 的干净证书提取也不能免费假定。
2. **明确区别于自己的最强常规基线。** 在相同成对评分、成本、可行集合、更新和 tie-breaking 下，成对穷举基线与提议选择器采取相同动作。已有覆盖/子模成本思想可以解释合成算例；必须先明确并因果检验一个有用的表示或估计器差异，再讨论系统贡献。

此外，完整上下文依赖必须包含负空间查询，不能只缓存旧邻居；插入、删除和规则变化都可能使证据失效。当前公开工具说明尚未建立完整义务枚举、干净证书和安全的选择性规则调用。如果每个候选仍必须无条件完整重检，缓存可能只增加开销。引擎 DRC 一致性也不等于 foundry signoff。

本轮科学决定为 **park**，并非已确认的优质组合成果。重开顺序应是：最近方法/获奖实现查重 → 明确基线不同之处及纯数组策略等价测试 → 检查器接口和完整结果 union 的正确性 → 同 K0 的冷/热残余共享普查 → 同信息同成本的强传统与学习对照 → 完整连通、DRC、时序约束下的闭合时间评价。若普通成对选择达到相同前沿，或证据管理与 fallback 抵消节省，应停止该贡献主张。

### D05 / EDA-0010：互斥替换分支的精确时序状态分区

新题保留穷举全部候选、全部端点与 guard 输出的任务。它按每个计算操作实际读取的完整上下文，把不同替换世界分为等价类，分裂、共享计算，再在结果相同时重新合并。预测器和算法 agent 只能影响调度或缓存准入，不能用近似嵌入授权状态等价。

提出者主动保留一个重要负结果：对固定纯确定性 DAG、相同完整 key、足够容量的冷缓存和相同世界集合，普通全局 keyed memoization 与该分区计算相同的唯一 key 数量。因此不能声称分区本身节省更多基本计算；候选系统贡献只能来自更低的状态管理开销，或同字节上限下更好的调度/重算权衡。合成 DAG 的操作计数不是 STA 运行加速比。

当前范围只有固定拓扑、单场景、ideal clock 的最大/建立时间模型；真实引擎的负载回传、插值、tag、隐藏状态、循环和恢复依赖必须另行提取和验证。不支持的操作要回退到独立参考执行。近似合并导致 slack 符号变化不可用误差容忍掩盖，完整输出的展开成本不能省略。

第四轮科学决定为 **park**，两项 major、可修复的质疑得到独立支持：

1. **更近的表示方法已存在。** variational execution 的条件值、有效配置子集、兼容输入交集和相同结果合并，可在所限定的纯 DAG 上表达这些分支状态类。它不是整个 STA 系统已被复制的证明，却是不可缺少的近邻基线。应使用同语言、同电气上下文、同输出和同内存限制的公平提升值实现，明确一个具体状态管理差异，而不能只与普通 cache lookup 比。
2. **tasklist 存在 recorder 与普查的依赖环。** EXP-001 普查依赖已冻结 recorder，EXP-003 又在依赖 EXP-001/002 后才实现它。权限条款不能代替构建依赖。应拆为：所有者/权利与范围 → 源码、适配器和 schema → 单独获配额并同意的 recorder fixture → 代表性基线普查和方差估计 → 阈值与确认性方案冻结 → 新的精确 tasklist 双签 → 候选评价。

任何重开都应先解决上述差异与依赖，再验证完整引擎依赖及恢复，做等内存、等输入、等正确性和完整输出成本的评价。现有消费者的真实查询需求与“每候选完整端点向量”的研究合同也必须分别说明，避免用人为放大的工作量制造收益。多 agent、统一预测与拆分预测均需对同信息集中式算法比较；没有净收益的可选组件应删除。

本轮没有确认结构创新、工程加速或实验就绪，也没有据此断言所有专用分支管理研究都无价值。后续工作需另行授权，本批到此停止新增科学回路。

## 逐轮角色审计

详细英文表由八份冻结的独立规范审计生成，每轮覆盖三个科学角色和九项规则。N 表示在提供的证据范围内未发现违规，D 表示有证据支持的偏差，U 表示未解决。N 不是对隐藏行为的保证。

本批保留了元数据格式错误、分配内文件名枚举的启动顺序偏差、审计表列错位修正、协调工具输入清单遗漏、被隔离的部分轮次、平台筛查中断和网络重试。它们的性质和后果应分别说明，不能统一写成“全部合规”或“全部违规”。

尤其是旧 D05 challenger 的输入范围事件，独立复核支持协调者遗漏 consent 目标清单、共享目录授权存在歧义，以及旧角色如实披露了超出枚举范围的读取。现有证据未建立私有内容暴露或故意越界。原尝试保留且未计入有效四轮，三个新角色从干净检查点重跑；该事件不归责于新 challenger。

角色自述、冻结哈希、公开 JOB 和独立审计均有适用范围。没有读取私有工具轨迹或对话来声称穷尽检查；没有把科学问题尚未解决、论文不可访问或未测得收益自动归为行为违规。协调者修复传输，科学 verifier 裁定证据，任何一方都不替其他角色签署实验或弃用同意。
