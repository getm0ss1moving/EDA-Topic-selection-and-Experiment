# D02: RTL, formal verification and test

RTL generation/repair, simulation, formal/property verification, equivalence, coverage, DFT/ATPG and test generation.

Engineering metrics: Verified correctness, non-vacuous properties, coverage, bug detection, proof/test cost and engineer effort.

Boundary: Partition functional verification and manufacturing test explicitly; hardware security is included where it has a verifiable EDA workflow.

Proposer: `Codex-P02-VERIFY`. Challenger: `Codex-C02-VERIFY`. Shared verifier: `Codex-V01-DIGITAL`.
