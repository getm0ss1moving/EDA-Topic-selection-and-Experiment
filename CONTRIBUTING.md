# Contributing

Start with `AGENTS.md` and your assigned role harness. Use English in all research artifacts. Work on a `codex/` branch, run structural checks and submit a PR with file-based evidence. Never self-approve. Before promotion, verify the current content digest, independently adjudicated objections and distinct registered review identity. Report contradictions with evidence; preserve superseded claims and negative results. Repository contents are public; publish only materials you have permission to redistribute.

No project-wide software or data license has been chosen yet. The owner must choose one before inviting reuse under a specific license. Third-party source records retain their original rights.
