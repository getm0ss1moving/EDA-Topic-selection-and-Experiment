# Historical AI proposer workflow

These files preserve earlier P/C/V configurations and instructions for provenance
and deterministic regression fixtures. They are not active launch settings.
Frozen releases, session IDs, consents and prior research reports remain intact.
The active workflow is `config/research-workflow.json` and `docs/WORKFLOW.md`.
`codex_loop.py` refuses execution commands in the current human-led checkout;
status inspection and offline unit tests remain available. Historical field names
such as `proposer_session` describe the original records, not a current AI role.
